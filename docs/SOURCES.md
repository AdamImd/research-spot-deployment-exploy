# Public sources and pins

- [ReLIC](https://github.com/rai-opensource/relic/tree/27f8033c5064d32f049a17accb71cd1091422878):
  original source, released checkpoints, Spot assets and research license.
- [Exploy](https://github.com/rai-opensource/exploy/tree/05f9dc3b2e589abdae8de942e8c6749e7a123c88):
  native environment export framework used by this graph.
- [Spot SDK](https://github.com/boston-dynamics/spot-sdk): pinned Python SDK 5.1.1.
- [Joint Control API](https://dev.bostondynamics.com/docs/concepts/joint_control/readme):
  robot-specific joint-control access and high-rate interfaces.
- [spot_rl_inference](https://github.com/SaxionMechatronics/spot_rl_inference/tree/dee987abc8c27e6542ba95fefa8e16390af5c1f9)
  and [spot_rl_train](https://github.com/SaxionMechatronics/spot_rl_train/tree/6bd031d8f89aa99ad7a4b2050a792ddb40345f6d):
  comparison references, not ReLIC's observation contract.

Original export and source hashes are bundled with the model. See
[third-party notices](../THIRD_PARTY_NOTICES.md) for license scope.
